# UZB ROYALE 🇺🇿

**UZB ROYALE** — O‘zbekiston tabiati va me’morchiligidan ilhomlangan original, brauzerda ishlaydigan 3D battle-royale prototipi. Bu PUBG darajasidagi tayyor mahsulot emas: hozir biz o‘ynaladigan uchinchi shaxs shooter asosini, xarita va jang mexanikalarini bosqichma-bosqich qurmoqdamiz.

## O‘yinni ochish

- **Jonli demo:** https://bekiuz.github.io/uzb-royale/
- **Kod:** https://github.com/bekiuz/uzb-royale

Loyiha alohida build talab qilmaydi. GitHub Pages orqali joylashtiriladi; Three.js kutubxonasi CDN’dan yuklanadi. Birinchi ochishda internet aloqasi kerak.

## Boshqaruv

### Kompyuter
- **W / A / S / D** — harakatlanish
- **Sichqoncha** — kamerani burish
- **Chap tugmani bosib turish** — avtomatik otish
- **O‘ng tugmani bosib turish** — nishonga yaqinroq olish va kamerani yaqinlashtirish
- **R** — o‘qni qayta to‘ldirish
- **Shift** — tez yugurish
- **Space** — sakrash
- **G** — qisqa muddatli skan
- **F** — yaqin tibbiy to‘plam yoki signal ta’minotini olish
- **M** — katta xaritani ochish/yopish
- **Esc** — pauza

### Telefon
- Chap joystick — yurish
- Ekranning o‘ng tomonini surish — kamera
- **OTISH** tugmasini bosib turish — uzluksiz otish
- **SAKRASH**, **SKAN**, **OLISH** va **EGILISH** tugmalari
- Telefonni gorizontal holatda ishlatish tavsiya etiladi.

## Prototipda mavjud

- O‘zbekiston muhitidan ilhomlangan aralash xarita: shahar, mahalla, aerodrom, sanoat hududi, paxtazor, cho‘l, tog‘li ko‘l va qadimiy qal’a.
- Teksturalangan yer va asfalt, yumshatilgan relyef ranglari, egri daryo tasmasi, notekis tog‘ siluetlari, daraxtlar, ko‘cha chiroqlari va elektr ustunlari.
- Uchinchi shaxs kamerasi, taktik qahramon, dubulg‘a, zirh, ryukzak va original karbin modeli.
- Kamera yaqinlashtirish, tepish/recoil, og‘iz chaqnashi, gilza chiqarish, vaqtinchalik o‘q izlari va zarba belgisi.
- Nishon tekshiruvi: qahramon raqibni ko‘rgan chizig‘i bo‘yicha urishga harakat qiladi; binolar o‘q yo‘lini to‘sadi. Boshga tekkan o‘q ko‘proq zarar yetkazadi.
- UZ-7 prototip karbini, 30 o‘qlik magazin, zaxira o‘q va qayta to‘ldirish.
- Bot-raqiblar, sog‘liq va himoya ko‘rsatkichlari.
- Minimap, keng xarita, ta’minot qutilari va qisqaradigan xavfsiz zona.
- Grafika darajasi, FPS chegarasi (30/60/90/120), kamera sezgirligi va ovoz sozlamalari.
- Haqiqiy render FPS ko‘rsatkichi; sozlamalar brauzer xotirasida saqlanadi.

## Hali mavjud emas

- Internet orqali multiplayer, xona/matchmaking va 100 o‘yinchili jang.
- Haqiqiy server ping’i. Server ulanmagani uchun HUD’da **OFFLINE** ko‘rsatiladi.
- Parashyutdan tushish, boshqariladigan transportlar, to‘liq inventar va loot tizimi.
- Ishlab chiqarish darajasidagi 3D modellar, animatsiyalar, audio yozuvlari va anti-cheat.
- PUBG Mobile’ning aynan nusxasi. UZB ROYALE o‘z nomi, xarita konsepsiyasi va original resurslariga ega bo‘lishi kerak.

## Texnologiya

- HTML, CSS va JavaScript
- Three.js (CDN)
- GitHub Actions + GitHub Pages

Keyingi bosqich: o‘yinni haqiqiy qurilmalarda sinash, o‘q yo‘lini va to‘qnashuvlarni yanada takomillashtirish, animatsiya/transport qo‘shish, mobil unumdorlikni optimallashtirish va keyin alohida multiplayer serverini loyihalash.
